# FlyStaff Planner

Aplicação para Windows que ajuda a pesquisar e comparar viagens através do FlyStaff.

## Descarregar e instalar

1. Abre a [página de versões disponíveis](https://github.com/Zakazy/FlyStaff-Planner-Releases/releases).
2. Escolhe a versão beta mais recente.
3. Na secção **Assets**, descarrega o ficheiro `FlyStaffPlanner-Setup-….exe`.
4. Executa o instalador e segue as instruções.

## Atualizações

A partir da Beta 16, a aplicação verifica se existem novas versões. Também podes procurar atualizações através da opção **Atualizações** na app.

## Acesso ao FlyStaff

Cada utilizador inicia sessão com a sua própria conta FlyStaff. A disponibilidade apresentada pode mudar e não garante o embarque.

## Testes e feedback

Esta aplicação está em fase beta. Se encontrares um problema, utiliza **Exportar relatório desta sessão** e envia o ficheiro diretamente ao responsável pelos testes.

Não publiques credenciais, cookies, dados pessoais ou relatórios de diagnóstico neste repositório.

Este repositório disponibiliza os instaladores e as atualizações. O código-fonte é mantido separadamente num repositório privado.
